# 推理过程可视化 — 排期表

## 人员

| 角色 | 负责 | 
|------|------|
| A（BioDSA 后端） | 事件模型、提取器、广播器、Stream Hook、MCP Server |
| B（WeKnora 后端） | 事件类型、Handler、MCP 并行读取、持久化表、API |

---

## Week 1

| 天 | A（BioDSA） | B（WeKnora） |
|----|------------|-------------|
| D1 | 事件模型 events.py（7 种 dataclass + entity_type 归一化）| 调研：EventBus 扩展点、MCP Execute 链路、StreamManager 接口 |
| D2 | 提取器 extractor.py（tool_name 映射表 + subgraphs 兼容）| 调研：数据库 migration 机制、现有 SSE 事件格式 |
| D3 | 广播器 broadcaster.py（Queue + emit_sync + subscribe + 环形缓冲区）| EventAgentGraph 事件类型 + 数据结构定义 |
| D4 | Stream Hook（agent.py generate() 接入）+ MCP Server（/progress 路由、线程池、session_id 参数）| AgentStreamHandler 订阅转发 + MCP Execute 内 goroutine 并行读取 |
| D5 | BioDSA 端到端验证（curl 验证 SSE 流）| WeKnora 端到端验证（EventBus → StreamManager → 模拟前端收事件） |

**W1 里程碑：图谱事件从 BioDSA 穿透到 WeKnora StreamManager，事件格式可用。**

| D9 | 合流联调：BioDSA + WeKnora 端到端 | 合流联调：BioDSA + WeKnora 端到端 |
