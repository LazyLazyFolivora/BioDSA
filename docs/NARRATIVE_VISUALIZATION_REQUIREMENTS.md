# BioDSA 推理过程可视化 — 需求文档

## 问题

当前 BioDSA agent 的推理过程不可见。用户提问后经历 3-5 分钟的等待，只得到一个文本结果。这个过程像一个"黑盒"——用户不知道 agent 在做什么、发现了什么、结论是怎么来的。

传统的 agent 推理展示（步骤日志：调用了 X 工具、返回了 Y 结果）机械枯燥，无法让人感受到"科研探索"的过程。

## 目标

将 BioDSA 的推理过程从"黑盒等待"变成"一段可视化的科研探索旅程"。

核心体验：用户不是在看一个 agent 工作，而是在**观看一个知识网络在自己眼前生长**。

## 具体需求

### N1. 知识图谱实时生长

当 agent 在多个生物医学数据库中检索时，每发现一个实体（基因、药物、疾病、突变、通路等），就在画布上浮现一个新节点。每发现两个实体之间的关系（如"某突变导致某药物耐药"），就在它们之间画一条连线。

- 节点按实体类型用不同颜色区分（基因是蓝色、药物是红色、疾病是橙色等）
- 连线的粗细反映证据的强弱
- 如果发现矛盾证据，连线变红并闪烁提示
- 整个过程是连续的动画，不是一次性跳出来

### N2. 研究策略可视化

DeepEvidence agent 采用"广度优先搜索（BFS）+ 深度优先搜索（DFS）"的策略。可视化需要让用户感知到当前处于什么阶段：

- BFS 阶段：多个节点同时从各个方向浮现，展现"广泛搜索"的感觉
- DFS 阶段：在某个已有节点周围辐射出一圈新节点，展现"深入挖掘"的感觉
- 阶段切换时有明确的视觉提示

### N3. 实时进度面板

除了知识图谱，需要一个简洁的进度面板展示：

- 当前研究阶段（规划中 / 广域检索 / 深入挖掘 / 综合分析）
- 已用时间
- 各类实体的累计发现数量（基因 X 个、药物 Y 个...）
- 最近的重要发现（以自然语言描述，而不是工具调用名）

### N4. 嵌入 WeKnora 对话流

可视化不是独立页面，而是嵌入在 WeKnora 的对话界面中。用户在对话中提问后，回复消息卡片内展示知识图谱的实时生长过程。图谱生长完成后，下方附上完整的文本结论。

## 非目标（本期不做）

- 知识图谱的手动编辑、拖拽保存
- 历史 run 的回放
- 多 agent 并行可视化
- PDF 报告导出
- 手机端适配

## 验收标准

1. 用户提问后，图谱在 5 秒内开始出现第一个节点
2. 节点的出现有动画，不是瞬间全部显示
3. 颜色体系一致：同类实体始终用同一种颜色
4. BFS 和 DFS 阶段的视觉感受有明显区别
5. 进度面板的实体计数实时更新
6. agent 运行结束后，图谱保持静止，用户可以随意缩放、点击节点查看详情
7. 整个过程在 WeKnora 对话界面内完成，不需要跳转到其他页面
