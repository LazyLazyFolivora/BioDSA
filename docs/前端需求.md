# 推理过程可视化 — 前端需求（WeKnora）

## 问题

BioDSA agent 运行一次 3-5 分钟，期间用户只能等待。WeKnora 对话界面中只有一条消息，没有任何中间过程的反馈。

## 目标

在 WeKnora 对话界面内嵌入一个**实时生长的知识图谱**，让用户在等待期间能看到 agent 正在发现什么，而不是盯着一个空白的等待状态。

---

## 需求

### F1. 知识图谱实时生长

agent 在检索过程中每发现一个生物医学实体（基因、药物、疾病、突变等），前端收到事件后立即在画布上渲染：

- 新节点以**浮现动画**出现（不是直接显示），持续约半秒
- 不同类型实体用**不同颜色**区分，整个会话中颜色保持一致
- 实体类型和颜色：基因=蓝色、药物=红色、疾病=橙色、突变=紫色、通路=绿色、化合物=青色、靶点=深橙、文献=灰色

当两个实体之间发现关系时：

- 在它们之间画一条连线，线从起点**生长**到终点
- 连线粗细反映**证据强度**：强证据粗线，弱证据细线
- 如果是**矛盾发现**（与已有证据不一致），连线用红色虚线并短暂闪烁
- 关系类型用连线上的标签区分（如"靶向""耐药""关联"等）

### F2. 研究阶段展示

agent 的研究策略有两种模式，前端需要让用户感知到当前阶段：

- **广度检索阶段**：多个节点同时从不同位置浮现，画面活跃，给人"大范围扫描"的感觉。进度面板显示"正在广域检索..."
- **深度挖掘阶段**：围绕一个已有节点向外辐射新节点，给人"聚焦深入"的感觉。进度面板显示"正在深入挖掘..."
- 阶段切换时有**明确的视觉过渡**（如画布短暂缩放、或阶段标签动画）

### F3. 进度面板

知识图谱旁边需要一个紧凑的信息面板，实时更新：

- **当前阶段**：一行文字说明 agent 正在做什么（用自然语言，不是技术术语）
- **已用时间**：从开始到现在的计时
- **实体计数**：各类实体已发现的数量统计（基因 5、药物 3、疾病 1...），数字随发现实时递增
- **发现时间线**：最近几条重要发现的一句话描述，按时间最新在上，滚动显示

### F4. 嵌入对话流

- 知识图谱渲染在 WeKnora 的**消息卡片**内，不是弹窗或独立页面
- 卡片上方是知识图谱区域，下方保留 agent 的文本回复
- 图谱生长完成后可随意**缩放、拖拽、点击节点**查看详情
- 回复完成后图谱保持静止，不自动关闭

### F5. 节点交互

- **悬停**节点：高亮该节点及其所有关联连线，其他元素变暗
- **点击**节点：弹出信息卡，显示实体名称、类型、来源数据库、简要描述
- **缩放平移**：支持鼠标滚轮缩放和拖拽平移
- 右下角有一个小地图（缩略导航），方便在大图谱中定位

---

## 前端不负责的

以下能力由 BioDSA 后端提供，前端只负责消费和展示：

- 从 agent 推理过程中提取实体和关系
- 判断当前处于什么研究阶段
- 生成自然语言描述（最近发现、阶段说明等）

---

## 验收标准

1. 收到第一个事件后 1 秒内出现对应的视觉变化
2. 节点浮现有动画感，不是瞬间全部出现
3. 同类型实体始终使用同一种颜色
4. 广度检索和深度挖掘阶段的视觉感受有明显区别
5. 进度面板的计数随事件实时递增
6. agent 结束后图谱保持可交互（缩放、点击），不消失不卡死
7. 整个过程不离开 WeKnora 对话页面
