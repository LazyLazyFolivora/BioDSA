# BioDSA 推理过程可视化 — 需求文档

## 问题

BioDSA agent 运行一次 3-5 分钟，期间用户只能等待。agent 内部发生了什么、发现了什么、结论怎么来的——完全不可见。用户在 WeKnora 对话中看到的是一个黑盒。

## 目标

将 agent 的推理过程从"黑盒等待"变成**一张实时生长的知识图谱**。用户不是在等一个结果，而是在观​​看一个知识网络在自己眼前形成。

## 需求

### R1. 知识图谱实时生长

agent 在检索过程中每发现一个生物医学实体（基因、药物、疾病、突变、通路、化合物、靶点），前端立即渲染一个新节点。每发现两个实体之间的关系，就在它们之间画一条连线。

节点按实体类型用不同颜色区分，整个会话中颜色保持一致。连线粗细反映证据强弱。如果发现矛盾证据，连线用红色虚线并短暂闪烁。

整个过程是连续的、有动画的，不是一次性跳出。

### R2. 研究阶段可视化

agent 采用 BFS（广度搜索）+ DFS（深度搜索）策略。前端需要让用户感知当前阶段：

- 广度检索阶段：多个节点从不同方向同时浮现，给人"大范围扫描"的感觉
- 深度挖掘阶段：围绕已有节点向外辐射新节点，给人"聚焦深入"的感觉
- 阶段切换时有明确的视觉提示

### R3. 实时进度面板

知识图谱旁边展示：

- 当前研究阶段（用自然语言描述，不是技术术语）
- 已用时间
- 各类实体累计发现数量（基因 X 个、药物 Y 个……）
- 最近重要发现的时间线

### R4. 嵌入 WeKnora 对话流

- 知识图谱渲染在消息卡片内，不是弹窗或独立页面
- 卡片上方是图谱区域，下方保留 agent 的文本回复
- 图谱生长完成后可随意缩放、拖拽、点击节点查看详情
- 回复完成后图谱保持静止，不消失

### R5. 节点交互

- 悬停节点：高亮该节点及所有关联连线，其他元素变暗
- 点击节点：弹出信息卡（实体名、类型、来源数据库、描述）
- 缩放平移：鼠标滚轮 + 拖拽
- 右下角缩略导航小地图

### R6. 对话历史回显

- 用户再次打开历史对话时，图谱完整还原
- 不是重新跑一遍 agent，而是从存储中直接加载
- 图谱保持原样，可交互

## 非目标（本期不做）

- 知识图谱的手动编辑
- 历史 run 的回放动画
- 多 agent 并行可视化
- PDF 报告导出
- 手机端适配

## 验收标准

1. 用户提问后，图谱在 5 秒内开始出现第一个节点
2. 节点浮现有动画感
3. 同类型实体始终同色
4. BFS 和 DFS 阶段视觉感受有明显区别
5. 进度面板计数实时递增
6. agent 结束后图谱保持可交互
7. 整个过程不离开 WeKnora 对话页面
8. 关闭对话再打开，图谱完整恢复
